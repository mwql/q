CYD Home Hub

Install the touch-first home controller for CYD-2432S028. It has Wi-Fi setup, Sonoff/eWeLink control through Home Assistant, BLE discovery, and an optional IR remote.

  1. Use Chrome or Edge on desktop.
  2. Connect the CYD by a data USB cable.
  3. Hold BOOT, tap RST, then release BOOT if the browser cannot find it.

This installer needs a generated firmware file at firmware/cyd-home.bin. Build it once with the included release command, then host this folder over HTTPS.
