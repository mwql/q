About Mahdi

Starter Developer based in Kuwait 🇰🇼 • Passionate learner, builder, and bot creator.

My Journey into Technology

My passion for technology started in my childhood when I loved creating games. The thrill of bringing visual ideas and interactive mechanics to life on a computer screen ignited an enduring curiosity about software engineering.

Since those early sparks, I actively attended multiple coding clubs, explored programming languages, and earned an official Python certificate. Through hands-on problem solving and dedicated practice, I expanded my skills from scripting into full web development and automated server architectures.

While I am still at the beginning of my journey as a developer, I am constantly learning, writing cleaner code, and building new things every single day. I believe that consistent curiosity and practical projects are the keys to mastering modern software engineering.

What I Focus On

Currently, my main areas of interest and building include:

  • Modern Web Apps & PWAs: Designing responsive, fast-loading web applications with offline capabilities (such as my Weather Web PWA).
  • Automated Bot Ecosystems: Engineering 24/7 Discord bots powered by Node.js, Express, and Discord.js v14 with custom web administration dashboards.
  • IoT Integration: Interfacing software APIs with smart home hardware (eWeLink automation).
  • Writing Clean Code: Structuring maintainable code across HTML5, CSS3, JavaScript, and Python.
